# Media Folder

Upload your wedding photos, artwork, audio, or video files into this directory (`/public/media/` or `/media/`).

### How to use your uploaded images:
- Any image uploaded here (e.g. `/public/media/my-photo.jpg`) can be referenced anywhere in your wedding invite as:
  `/media/my-photo.jpg`

### Supported formats:
- Images: `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`, `.gif`
- Audio: `.mp3`, `.wav`, `.m4a`

You can also use the **CUSTOMIZE TEMPLATE** button in the top-left of the wedding invitation to upload images directly through the web browser.
